# Research

Scripts de análise em R. Cada projeto fica na sua própria branch, com o script e o histórico de commits dele; esta `main` guarda só o índice.

## Como usar

```bash
git fetch
git checkout tolac        # troca para o projeto
```

No RStudio, a aba **Git** troca de branch pelo seletor no canto direito. Cada branch traz o `Meus_Scripts_R.Rproj`.

Projeto novo: crie a branch a partir de uma vazia (`git checkout --orphan nome-do-projeto`) e acrescente a linha na tabela abaixo.
